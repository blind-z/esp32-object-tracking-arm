ESP32 Object Tracking Arm
A low-cost robotic arm that runs on an ESP32. You can drive it by hand from a web page, or let a webcam and OpenCV find a red or blue object and have the arm pick it up.
I built it to see how embedded code, computer vision, networking, and a bit of geometry fit together in one system, using parts that are cheap and easy to find.
